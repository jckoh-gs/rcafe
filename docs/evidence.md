# 날씨 × 입맛 근거 자료 (Evidence)

PRD §4.3의 근거 목록. 2026-10-09 웹 검색으로 찾은 **초록·요약 수준** 자료이며, 원문 전체는 아직 확인하지 않았다(M0에서 확인).
결론: 방향성은 있으나 효과 크기가 작고 연구 간 결과가 엇갈린다. 서비스는 이를 **휴리스틱**으로만 사용한다.
